# Continual neural-symbolic cognition

The `Continual` coordinator integrates the existing hybrid runtime, cross-environment program synthesis, persistent executable skills, frozen neural experts, and a bounded recovery protocol. It does not alter the original single-inquiry `Hybrid` implementation. The host provides measurements and access; the learner selects its own supported queries, requests recalibration, increases synthesis cost when needed, and proposes composition plans. There is no unrestricted execution or external actuation.

## Mechanisms

| Mechanism | Executable implementation |
|---|---|
| Cumulative executable abstraction | Select up to six distinct validated word programs with compatible audited scope. Substitute their syntax into new search expressions at a unit macro cost, tracking actual source dependencies. Fresh training, reserved audits and boundary probes are still required. |
| Progressive neural recognition | Preserve up to eight independently verified experts. Check existing experts against a fresh labeled probe set. If none passes, train a new head on fresh calibration samples, using raw normalized channels and hidden features from up to two frozen parent networks. Verify on a disjoint labeled set before use. Maximum lateral depth is three. |
| Persistent strategy learning | Copy guidance weights from the latest live episode of the same family. Reset the world model for each new episode. Guidance ranks ties; symbolic evidence remains authoritative. |
| Bounded deliberation | Increase synthesis budget from one to two or three on unsuccessful word inquiries, with host-granted replacement evidence and at most two retries. This is deterministic budget escalation, not learned or self-modifying search code. |
| Self-selected experiments | After the ordinary independent audit gate, choose up to two additional uncovered inputs per width by a boundary-coverage heuristic. The host can refuse access, in which case the episode remains invalid. |
| Recovery and consolidation | Quarantine contradicted records and their recorded dependents; open a fresh episode in the same task family and scope after a host grant. Do not mix old-regime labels into new candidate fitting. Keep unaffected validated records and eligible neural experts. |
| Predictive composition | Iterative-deepening search over the finite transition graph generated by retained word skills, with explicit operands and a bounded goal depth. Every proposed transition is computed from a live verified program; the proposal conveys no physical authority. |

A `ProgressiveRecognition` head receives the three raw channels plus each frozen parent's hidden activation vector mapped from [-1,1] to [0,1]. It trains by the existing dense tanh/sigmoid gradient update. A parent contributes actual computed features, not a name or simulated signal; the parent copy remains unchanged during training. The first expert is a 3–6–1 network (31 parameters). A depth-two expert with one such parent adds a 9–8–1 head (89 trainable parameters, plus 31 frozen parent parameters). Networks and their lateral dependencies are selected using labels, not inferred solely from unlabeled observations. The maximum supported depth is three; the measured campaigns exercised depths one and two. A larger or deeper network is not automatically superior.

## Lifecycle and evidence

An episode has an immutable identifier within a journal. The initial request is `sensor_check`. The host provides distinct normalized three-channel samples labeled 0 or 1. If no existing expert correctly classifies every check sample, the learner requests `calibrate` followed by `verify_sensor` on independent samples. The learner then uses the hybrid inquiry protocol (`train`, `environment`, `audit`). Training outcomes are encoded as rasters; audits are explicit measurements independent of neural decoding. Additional `probe` requests are made outside all declared training and audit pools when such inputs exist. Only after these checks finish does `complete` authorize `predict` for that episode.

The host controls access and supplied measurements. All accepted measurements are trusted as observations, not as cryptographic proof of their real-world correctness. A `challenge` is a later temporal measurement within a validated episode's scope. It may revisit a previously observed input because the environment may change. A conflicting observation invalidates the corresponding rule and conservatively invalidates dependents, including those using the source's neural representation or strategy. This conservative dependency policy can discard independently correct knowledge; it is not a proof that every descendant is wrong. When the active episode is affected, the next request is `recover`, requiring the host to grant new pools. A fresh episode is created; historical invalidated records are retained but never used for prediction or planning. A refusal, exhausted retry limit, or unresolvable model family leads to abstention. The recovery pools must be internally disjoint, but may overlap earlier attempts because temporal re-observation may be necessary. No guarantee of external measurement independence follows from the interface.

The journal is flat: it contains begin, next, answer, deny and challenge events, not nested source checkpoints. Each retained model is reconstructed by replay from the original seeds, observations, calibration updates, selection decisions and audits. A stored fingerprint covers derived state, network weights, experts, strategies and the active inquiry. SHA-256 detects corruption; it is not a signature against a malicious party able to forge an entirely new coherent history. The checkpoint is bounded to 48 MB, 24,000 recorded events and 160 episodes. It uses atomic replacement for single-writer local operation. Cross-machine floating-point byte identity is not established.

## Host interface

```python
from ix_zero.continual import Continual

m = Continual(max_budget=2)
episode = m.begin('word', [3, 5], 3, train, audit, seed=7, budget=1)
while True:
    request = m.next()
    if request['action'] in ('complete', 'failed'):
        break
    # Your host implements the measurement/access protocol.
    m.answer(host_measurement(request))
prediction = m.predict(m.active, (5, 3, 0))
m.save('ix-zero-continual-state.json')
restored = Continual.load('ix-zero-continual-state.json')
```

`train`, `audit` and `host_measurement` in the example are host-supplied inputs, not library functions. A complete executable host is provided in `ix_zero.continual_experiment`. For local integration, `python -m ix_zero.continual_cli` accepts JSON lines with commands `new`, `begin`, `next`, `answer`, `deny`, `predict`, `challenge`, `compose_plan`, `status`, `save`, and `load`. `begin` takes family, widths, initial, train, audit, seed and budget; `answer` takes value; `predict` and `challenge` take episode and input, with challenge also taking value. `compose_plan` takes width, start, goal, skills (episode identifiers), operands and max_steps. `save` and `load` take path. The host interface is intentionally narrow and local.

## Experimental protocol

Two complete deterministic campaigns, starting at seeds 510000 and 610000, use authored finite tasks. Each campaign contains three matched five-law sequences with four arms: full reuse, no reuse, neural reuse without executable-skill reuse, and full skill reuse without progressive lateral features. All arms have the same initial and maximum two-gate synthesis budget. They receive the same host law, sensor mapping and initial pool partition for each matched task; retries can request different partitions. The evaluator reports each arm's actual holdouts and the intersection of unobserved inputs across arms, excluding all granted pools and extra probes in every attempt. No held-out label is supplied during fitting. The two alternating sensor polarities share the same three-channel representation. No neural superiority or broader real-world sensor performance is assumed.

Each campaign also includes three spatial regime changes, three hidden-corner-exception trials, three paired fixed-versus-adaptive depth controls with an outside-grammar arithmetic control, and one hundred successive inquiries alternating four word-law types and spatial transition configurations. The latter are repeated authored families, not one hundred independent novel cognitive domains. Retention is checked across each retained law's entire declared finite domain after journal replay, including previously seen inputs. Separate held-out counts are recorded before replay. This is persistence of scoped programs, not an unrestricted ability to learn new task families.

The successful five-law sequence acquires left-shift-by-two and right-shift-by-two, then composes these learned executable abstractions to synthesize left-shift-by-four, right-shift-by-four and a left-then-right composition under the same two-gate budget. Source expressions are never supplied to the learner. The composed programs record their macro dependencies. Neural reuse by itself does not rescue these grammar-limited failures. Lower total requests in the full arm partly reflect the absence of failed retries; the result is not a universal sample-efficiency measure. Lateral feature stacking had no measured advantage over independent expert heads in this protocol.

## Scientific limitations

This implementation does not implement an unrestricted recursive neural reasoner, arbitrary representation invention, general-purpose vision, natural-language conversation, open-world goals, unrestricted self-improvement or neural planning over arbitrary learned world models. Iterative-deepening search uses verified finite transitions; the neural strategy remains a tie-breaker. No standardized AGI benchmark, externally blinded trial, independent novelty assessment, or scientific measurement of distance to AGI is reported. The finite grammar, environment families, budget, sensors and host permissions are supplied by the implementation. Runtime and storage grow with retained episodes and journal replay. The release is experimental, not an AGI or production deployment system.

## Three-level skill composition and goal search

An additional six-seed paired campaign tests a deeper executable dependency chain under the same two-gate budget. The learner first discovers double-left and double-right shifts, uses each to discover a four-shift operation, and then composes those two second-level skills into a third-level operation. The evaluator supplies observations, not expressions. The final program has eight expanded shift operations; its cost is two macro calls in the learner's vocabulary. These are specific finite-width executable abstractions, not arbitrary new primitives.

| Measure | Observed result |
|---|---:|
| Full skill-reuse arm, validated acquisitions | 30/30 |
| Skill-reuse-disabled control, promotions | 13/30 (one false promotion) |
| Third-level dependency chains verified | 6/6 |
| Third-level control acquisitions | 0/6 |
| Full arm, common held-out predictions | 24,576/24,576 correct |
| Control, common held-out predictions | 11,459 correct, 382 wrong, 12,735 abstentions |
| Finite shortest-path planning checks | 6,144/6,144 (1,248 reachable goals) |
| Flat journal replays | 12/12 |
| Transitive invalidation after a contradicted source | 6/6 |

The control's false promotion was a constant-zero hypothesis for a four-left-shift law (seed 710300). It made 383 wrong predictions on its own holdout, of which 382 are in the common heldout partition. An initial expectation that neither arm would make any wrong prediction was therefore not met. This negative observation is retained; no change was made to the learner in response to this trial. The executable acceptance check requires the full arm's verified chain, predictions, planning and invalidation to pass; it does not require the disabled-reuse control to be error-free. This is important: even the strengthened finite probes and audits do not guarantee correctness, especially when the true expression is outside the active vocabulary.

Planning is evaluated over every start/goal pair in a five-bit domain with the first two learned skills as available actions, a fixed second operand of zero, and a four-step limit. An independent breadth-first oracle calculates reachable goals and minimum path lengths; each proposed transition is also checked against the host's arithmetic. It does not test physical action, open-world planning, or neural-model superiority.

# IX-Zero 5.0.0 — grounded semantic and relational research

This is an additive research candidate, not a claim of completed AGI or completion of every research requirement. The version remains 5.0.0. The preceding 5.0 expanded candidate and all of its experimental results are preserved. No pretrained model or external AI inference is required by the new native mechanisms.

## 1. Research hypothesis and implementation

A learner should be able to derive the meaning of an unfamiliar action from observations of consequences, choose new experiments when rival hypotheses disagree, transfer learned semantics to a different vocabulary, and use acquired models to plan. This build tests that hypothesis in a bounded, explicitly typed object world. It does not establish arbitrary semantic understanding, consciousness, unrestricted autonomy, or independent discovery of every representation primitive.

| Mechanism | Executable implementation and scope |
|---|---|
| Grounded lexeme induction | `grounded_semantics.py`: one previously unknown action token and 1–3 distinct named entity tokens, in varying positions. Infer the verb position by grounding entity tokens against observed objects. Induce simultaneous role-relative attribute writes using generated integer expressions and conditional effects. Object/attribute structure and expression grammar are authored; labels and target programs are not supplied to search. |
| Self-generated diagnostic inputs | `generate_probes`: construct new states by equating role-relative attributes, changing signs, testing zero and unit shifts. Choose among proposed interventions using disagreement of viable hypotheses. The generic perturbation operators are engineered, but individual query states are generated by Zero; no probe labels are used until measured. |
| Active learning and audit | Candidate generation is based on training observations. Queries are selected by prediction disagreement. Audit input coordinates are visible, audit labels remain withheld until the candidate is frozen. Ambiguity, contradiction or out-of-grammar effects block promotion. Observational equivalence is not universal proof. |
| Analogical semantic transfer | Search role permutations and field bijections over previously audited action models, rebind generated executable expressions, check against fresh observations and audit. A contradiction withdraws the source and syntactically dependent transfers. |
| Goal planning | Breadth-first search on predicted states using learned actions, not a supplied transition graph or required route. The evaluator then executes the predicted plan in a separate environment and checks the actual partial objective. Up to 8-step planning, 100,000 distinct states, 200,000 transition attempts. Predicted success is not actual success until independently measured. |
| Relational grid inference | `grid_relational.py`: generate output shape relations, coordinate frames, component-size/rank features, direct pixel hypotheses, conditional combinations and learned finite value mappings. Search minimum-complexity consistent models; tied predictions must agree; abstain on unknown mapped values, ambiguity or exhausted budget. The feature generator is authored; selected executable mappings and conditionals are inferred. |
| Real software measurement | `browser_semantic_experiment.py`: run an actual trusted local Chromium application; fill visible typed state and action controls, click the Apply button, read visible results, acquire models and execute a learned plan. The UI form contract is supplied; no general-purpose desktop or commercial website competence is asserted. |

The workspace has native `semantic_inquire`, `semantic_transfer`, `semantic_probes`, `semantic_predict`, `semantic_plan`, `semantic_challenge`, and `grid_relational` commands. `task` routes typed object-state examples and partial-state objectives to the new learner/planner; old numeric and controlled-language routes are retained. The research journal is now version 4 with replayed semantic models/dependencies; versions 1–3 remain supported. No learner-generated host source code is executed. The checkpoint hash is integrity checking, not authenticated provenance.

## 2. Executed action-language experiments

Two disjoint 12-seed campaigns (`351300`, `352300`) use five reference action families. Each seed randomizes opaque field/verb names and word order, supplies six measured training transitions per family, allows up to 16 additional labels selected from a generated pool, and holds back 12 audits and 32 final predictions. Final inputs have new entity IDs, five objects instead of three, and a larger integer value range. The evaluator defines the action families and typed environment; this is not independent natural-language grammar acquisition.

| Arm | Correct on four supported families (3,072 final cases) | Wrong | Abstain | Additional queries | Goal plans executed successfully |
|---|---:|---:|---:|---:|---:|
| Active disagreement | 3,072 | 0 | 0 | 564 | 24/24 |
| Random query | 160 | 0 | 2,912 | 1,536 | 0/24 |
| No inquiry | 0 | 0 | 3,072 | 0 | 0/24 |
| Conditional expressions removed | 2,304 | 0 | 768 | 43 | 24/24 |
| No acquired models | not a prediction arm | — | — | — | 0/24 |

Each of copy, swap, equality-gated copy, and add-and-clear achieved 768/768 correct in the active arm. All 24 equality-gated rules are learned even though initial observations omit the triggering equality. Zero generates proposed equality states from role-field relations, then selects informative ones. No conditional expressions: 0/768 on this family (abstentions). The multiplication negative control yields 0/768 correct and 768 abstentions in every arm; it is outside this action learner's available expression grammar, even though other IX-Zero numerical engines support multiplication. Automatic cross-mechanism rescue of this action family is not implemented.

Active and random arms use identical expression candidate spaces, training data, proposed input pools, and maximum query budgets. Actual queries differ because the active learner stops when its exposed hypotheses agree. Accepted models consume audit labels; ambiguous controls do not, so total measured labels and runtime are NOT matched. The conditional-removed grammar is smaller. The two-click goal tasks use fresh object IDs and specified partial target values; the reference evaluator does not supply the required action path. The six-query pilot underperformed (5 of 8 supported models promoted, 0/2 goals); the increased query budget is an explicit experimenter decision. The separate three-seed 16-query pilot and two fresh full campaigns are preserved.

## 3. Executed cross-vocabulary transfer

Two disjoint 12-seed campaigns (`361200`, `362200`) acquire the four source rules, then present another environment with new opaque field and verb names, reversed noun roles, and a new lexical slot. Target training comprises only two measured transitions per family, a maximum of four additional probe labels, and 12 independent audits before promotion. Holdouts contain six fresh objects and a larger value range. Target rules are structurally analogous by design; transfer to unrelated semantic structures is unproven.

| Target adaptation | Correct / 3,072 | Wrong | Abstain | Additional queries | Promoted models / 96 |
|---|---:|---:|---:|---:|---:|
| Rebind acquired relational models | 3,072 | 0 | 0 | 31 | 96 |
| From-scratch synthesis, same small target label cap | 0 | 0 | 3,072 | 384 | 0 |
| Transfer with empty source memory | 0 | 0 | 3,072 | 0 | 0 |

Source training is an additional cost. Rebinding tests complete-model permutations, whereas scratch synthesis tests factored attribute expressions; their candidate counts are not comparable units of compute. The four target families are the same underlying mechanisms as the source. This establishes a particular form of analogical semantic transfer, not unrestricted learning of arbitrary grammars. Every run also performs a deliberately falsified contradiction control; the original copy model and its dependent transfer are withdrawn. It is not a real physical regime change.

In the same 24 runs, separate authored unary increment and ternary mixed-field addition actions are acquired from eight training transitions and up to 24 new probes. Both yield 768/768 correct shifted holdouts (1,536/1,536 combined). These actions test varying grounded argument counts, not unrestricted language syntax.

## 4. Actual browser execution

Two seeds (`371100`, `371101`) run the typed local form inside Chromium. Training and audit outcomes are obtained through actual browser button clicks and visible result text rather than through a simulated Playwright adapter. For final cases, a separately implemented Python reference is also compared with the application's JavaScript output. The actual run produced 64/64 correct held-out transitions, 64/64 agreement between browser and Python reference, and 2/2 achieved goals, using 260 actual button clicks including training, inquiry, audit, holdout and plan execution. The supplied form labels, state serialization and trusted local application are an authored interface. This does not demonstrate general GUI discovery, live network research, or Windows desktop competence.

## 5. Public ARC-AGI-1 diagnostic

The ARC official benchmark contains 400 training and 400 evaluation tasks, and the project warns against repeated tuning on evaluation labels. See https://github.com/fchollet/ARC-AGI . This diagnostic is deliberately much smaller: three previously exposed tasks plus three compact public training tasks retrieved through the evaluator's web source display after raw download failed. The six numerical datasets are manually transcribed; no upstream byte identity is asserted. `arc-provenance.json` records exact URLs, local hashes, task selection/exclusions and the frozen relational solver hash. Candidate subprocesses receive demonstrations and unlabelled test inputs only. The earlier three exposed tasks are NOT independent blind evidence.

No incorrect non-abstained predictions were produced in this small diagnostic. All arms use a maximum of 5,000 candidates but candidate units, actual counts and compute differ. The new solver repaired two previously exposed failures. On the three newly selected training tasks the prior object and new relational solver each solved the same single task. The sole evaluation-set task remains unsolved. This is neither a representative ARC sample nor an official ARC score, and does not establish superiority on independent tasks. No solver changes were made after opening fresh task content. Future evaluation must use unseen tasks selected independently and a frozen implementation.

## 6. Reproduction

Standard library only for native mechanisms; Python 3.11+. Actual execution: Linux/Python 3.13.5. Run from repository root:

```sh
python -m unittest discover -s tests -v
python -m ix_zero.semantic_experiment --trials 12 --seed 351300 --check --output fresh-primary.json
python -m ix_zero.semantic_experiment --trials 12 --seed 352300 --check --output fresh-confirmation.json
python -m ix_zero.semantic_transfer_experiment --trials 12 --seed 361200 --check --output fresh-transfer-a.json
python -m ix_zero.semantic_transfer_experiment --trials 12 --seed 362200 --check --output fresh-transfer-b.json
python -m ix_zero.external_eval results/v5_grounded/arc_inputs --budget 5000 --modes original objects relational --output fresh-arc.json
```

For fresh external evaluation replace the path with the official ARC corpus directory; this included diagnostic is already exposed. Optional actual local browser experiment, requiring approved Playwright/Chromium installation:

```sh
python -m pip install ".[browser]"
python -m playwright install chromium
python -m ix_zero.browser_semantic_experiment --trials 2 --seed 371100 --output fresh-browser.json
```

On Linux the executed test specified `--browser-executable /usr/bin/chromium`. An optional local browser test is not part of the standard-library CI. `python -m ix_zero.research_cli` opens the JSON-lines interface. `semantic_probes` takes `train` (rows `[ [world, action_tokens], observed_world ]`); the generated inputs have no labels. An authorized measurement provider must execute them. `semantic_inquire` and `semantic_transfer` accept `train`, `pool`, `audit` in this same labelled form for deterministic offline replay. `semantic_predict` takes `s` and `words`; `semantic_plan` takes `start` and `goal` partial attribute mapping, plus optional `max_depth` and `state_budget`. `semantic_challenge` takes `s`, `words`, `observed`. `grid_relational` takes `train` and `inputs`, optional `budget`. Read-only live research remains available through a `research` goal; successful live retrieval is not claimed (see the executed failure trace).

## 7. Completion ledger and non-negotiable claim boundaries

| Objective | Status after this build |
|---|---|
| Preserve prior v4 and v5 capabilities and evidence | Retained, regression verified; see final validation. |
| Unified representations and mechanism selection | Typed dispatch connects new grounded action learning/planning and prior engines; unified arbitrary semantic substrate remains unresolved. |
| Semantic grounding and representation discovery | Learned role-relative expressions, lexical slots, field mappings, coordinate features and conditional programs; primitives/object schema are authored. General natural-language understanding, perception and autonomous ontology discovery remain open. |
| Autonomous inquiry | Actual self-generated finite interventions and prediction-disagreement selection; query generation operators authored. Unsupported multiplication action cannot be rescued automatically. |
| Cognitive self-improvement | Prior bounded program revision retained; new transferable semantic rule vocabulary, dependent withdrawal and planning. No unrestricted architectural invention or self-rewriting. |
| Creative reframing | Prior route experiment retained; new partial-state goal planning allows alternative learned action routes, not arbitrary assumption discovery. |
| Developmental memory | Retained learned programs, new audited action models and analogical mappings with replay and dependent invalidation. |
| Real internet and computer use | Prior read-only HTTPS and local browser integration retained; actual browser semantic experiment executed. Live HTTPS attempt again failed DNS. General-purpose software discovery, arbitrary authorized site interaction, Windows desktop competence, and autonomous research-to-general-executable-knowledge remain unproven. |
| Donor capability integration | Selected native Sally mechanisms already vendored and retained. Julia, GNAT and GPRbuild unavailable; full native IX-AGI/IX-BlackFox integration and complete parity not achieved. |
| Independent external benchmarks | Small public ARC diagnostic with exact-match evaluator; no broad independent evaluation or official score. |
| DreamCoder/PushGP baselines | Previous internal enumerative/random/evolutionary controls retained; actual named systems remain unrun. |
| Noise, calibration and truth | Earlier multi-source and corruption experiments retained; correlated evidence corruption and general epistemic reliability unresolved. |
| Intellectual exploration | Model and action search explores alternative valid solutions in its bounded world; no hidden claim of arbitrary unrestricted intelligence. |
| Independent scientific review | Executed controls, raw observations, failures, manifest, replay and separate worker provided. No independent third-party replication claimed. |

This iteration closes a narrow but important semantic grounding gap. It does not close the underlying AGI problem. The remaining missing prerequisite is broad, independently learnable representations and mechanisms that transfer beyond structurally related typed domains. Neither adding more interfaces nor relaxing permissions establishes that capability. Actual engineering validation is not a scientific AGI verdict.

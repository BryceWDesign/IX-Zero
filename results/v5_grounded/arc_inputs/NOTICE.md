# External ARC-AGI-1 diagnostic data

The six JSON files reproduce the integer-grid examples distributed by François Chollet and contributors in the ARC-AGI repository (Apache License 2.0), https://github.com/fchollet/ARC-AGI . They are third-party benchmark data, not IX-Zero-created tasks, and are not subject to IX-Zero's own noncommercial license. See `LICENSE-APACHE-2.0` and upstream `LICENSE`. Modifications: whitespace/key order normalization and manual transcription of displayed raw JSON because direct file download failed; upstream byte-for-byte identity is NOT claimed. The source URLs and local SHA-256 hashes are in `../arc-provenance.json`. The learner subprocess receives demonstration pairs and unlabeled test inputs only. Do not use these already exposed tasks as a blind evaluation.
